02 / Registers
理解控制时间的位。

BIT NOTES / 点击位图
Timer / Reload Calculator
从 20 ms，算到 0xB800。
机器周期 = 12 / fosc；计数次数 N = 定时时间 / 机器周期。
本实验按传统 12T 8051 计算。其他芯片的定时器时钟应查对应手册；这里的 1T/6T 仅表示理想分频计算。
为什么 /256 和 %256？16 位初值被拆成两个 8 位数。47104 / 256 = 184 = 0xB8 是高字节；47104 % 256 = 0 = 0x00 是低字节。两者合并：(TH0 × 256) + TL0 = 47104。
Parallel Timelines / Main & ISR
CPU 暂停扫描，T0 触发采样。
定时器是硬件；中断服务和显示函数仍由同一个 CPU 先后执行。

20 ms 是输入采样的名义间隔。它不等于一轮显示扫描周期，也不是每一位点亮 20 ms。中断响应与软件重装有开销，连续两次采样的实测间隔会有少量偏差。无滤波时，20 ms 采样也不能保证机械开关完全消抖。


MODE 1 / 本实验
16 位计数，20 ms 一次
可容纳 18432 次计数，初值 0xB800。每次中断手动重装即可。
MODE 2 / 可实现的替代
8 位自动重装，需要累计
11.0592 MHz / 12T 下单次最长约 0.2778 ms。可设 256 次计数、中断累计 72 次，再采样一次：256 × 72 = 18432。
CHOICE / 为什么方式 1 更直接
中断次数更少
约 50 次/秒的 T0 服务即可采样；上述方式 2 方案约 3600 次/秒，需要软件计数。本实验方式 1 更易理解和实现。

60-SECOND EXPLANATION
试着连贯讲完这一段。
本实验用 8255 扩展输入输出。初始化时向控制寄存器写入 89H，使 PA、PB 工作在方式 0 输出，PC 高低四位都输入。PC 接八路开关，读取结果为 0 到 255。T0 采用方式 1，在 11.0592 MHz、12T 条件下装入 B800H，约每 20 ms 进入中断，重装初值并更新 value。主循环持续调用 display，在每轮开始把 value 复制到 n，再拆成个位、十位、百位。每位都先关位选、写段码、开当前位并短暂保持。PA 的段码经过 74LS240 反相后驱动共阴数码管，PB0 到 PB2 低电平分别选择个位、十位和百位。快速轮流扫描，就能看到完整三位十进制数。

04 / 8255 In This Experiment
给每个端口，安排一份工作。
8255 是可编程并行接口：三个 8 位端口，共 24 条 I/O 线。本实验将它们分配给显示与开关。


PA
决定亮哪些笔画
8 位段码输出，经 74LS240 反相后送 a、b、c、d、e、f、g、dp。
PA8255 = seg[n % 10];
PB
决定当前亮哪一位
本实验使用 PB0、PB1、PB2，低电平分别选个位、十位、百位。
PB8255 = 0xFE;
PC
读取八路开关电平
PC7—PC0 组成一个 8 位无符号数，不负责数码管位选。
value = PC8255;
8255 在这里做“普通并行 I/O”。本实验没有使用方式 1/2 的握手信号，没有使用 8255 外设握手中断，也没有使用 PC 按位置位/复位控制。20 ms 中断来自单片机 T0。

一次访问，硬件要知道三件事。
01
是不是选中我？
/CS 低有效。高位地址由片选电路译码，F000 不是芯片自带地址。
02
访问我内部哪个寄存器？
A1、A0 区分 PA、PB、PC 和控制寄存器。
03
CPU 要读，还是要写？
/RD、/WR 低有效；数据经 D7—D0 传输。
XBYTE 发起的是外部数据空间访问。传统 8051 的 P0 复用低地址与数据，通常要用 ALE 配合锁存器保持低地址；P2 提供高地址。实际实验板可能已完成这些接口电路。
控制寄存器的读回能力随 8255 衍生型号而异，本实验只依赖写控制字，不用读回控制字验证配置。
Inversion / Segment Codes
从 PA 的 0，追到亮起的一段。
点击数字，观察段码经过 74LS240 后的变化。
段线端 / 共阴
位序：bit7…bit0 = dp、g、f、e、d、c、b、a。74LS240 使能时逐位取反，PA 端的 0 对应段线端的 1。
低电平有效要分别理解：PA 输出 0，经反相后使对应段阳极为高；PB 输出 0，是外接位驱动电路使该位选通。它们是两条不同的电气路径，不能简单归结为“8255 低电平就点亮”。
What You Need / Scope
围绕实验，掌握这六件事。
把芯片知识落实到每一次读、每一次写和每一次显示。
会说端口分工
PA→段线；PB→位线；PC←开关。PA/PB 输出，PC 输入。
会解释方式 0
普通输入输出；输出锁存，输入不锁存；无需握手。PC 方向可按高低四位配置。
会拆 0x89
10001001₂；D7 是方式标志，D6D5 与 D2 选方式，其余方向位决定输入/输出。
会看地址选择
/CS 选芯片，A1/A0 选内部寄存器，/RD、/WR 决定读写。
会说明输出锁存
写完 PA/PB 后，输出在后续代码或模式/复位操作改变前保持，不需要 CPU 持续“送电平”。
会区分软硬件任务
8255 负责并行接口；C51 负责拆位和扫描；T0 负责定时；反相器与位驱动负责电气转换。
本实验够用的知识范围：先掌握端口方向、方式 0、89H、地址选择、输入电平和动态扫描。方式 1/2 握手时序、PC 按位控制属于后续扩展；不能把它们当成本实验已经使用的功能。
