L001 / 对应讲解

词义与表达

table 在赌博场景指赌桌或赌局。结合 casino，可将 run the tables 理解为在各赌桌上连连获胜、占据优势；不要逐词译成“跑桌子”。常见相近表达 run the table 在不同比赛中有特定含义，不能把歌词的复数形式当作适用于所有场景的固定规则。

句法要点

主干 The casino does not like…；when you run the tables 给出不受欢迎的情境。like 后直接接 when 从句是口语化表达，正式写作可改为 does not like it when… 或对象更明确的表述。

文本直接表达文字直接说赌场不喜欢这种获胜局面。

合理推断赌场可以象征靠既有规则获利的组织，人物的成功打破了利益平衡。

开放解读／边界也可读为人物自认遭体制排斥的视角，不能据此断言所有现实赌场都采取同一种行为。

词义与表达

词义与表达

L007 / 对应讲解

词义与表达

liberated 表示获得自由；libertine 是带道德评价的“放荡者”，不只是自由随性的人。long for home 是渴望家、思念家。相近词形与重复起音把自由感和放纵并置。

04

PATTERNS / FROM SONG TO SENTENCE

短语与句法

结构名称采用词典形式或教学抽象式；它们不是完整歌词引文。P10、P12 等主题拓展会明确标注。语法例句全部原创。

P01 / S2 / 信息传播 / 教育 优先掌握

capture someone's attention

吸引某人的注意；关系段中是“被吸引”。

结构
capture + 所有格 + attention；与 pay attention to（主动注意）区别。
误区
不能写 capture someone to attention；attention 在这里不可数。
写作迁移
正式语域可用 draw public attention to…；to 后接被关注的问题。

A concrete example can capture readers' attention more effectively than a vague slogan.

一个具体例子比模糊口号更能吸引读者的注意。

P02 / S1 / 个人成长 / 归属 优先掌握

long for + noun / long to + verb

渴望某物 / 渴望做某事；本歌涉及归属。

结构
for 是介词，后接名词；to 在 long to do 中是不定式标记。
误区
不要写 long for return 表达“渴望返回”；可以写 long to return 或 long for a return。
写作迁移
情感强时保留 long；普通意愿可改为 hope for / hope to。

Students may long for independence while still needing guidance.

学生可能渴望独立，却仍然需要指导。

P03 / S2 / 信息判断 / 公共治理 优先掌握

be free of / from + noun

没有某种不受欢迎的东西；关系段涉及矫饰。

结构
free 是形容词；of / from 后接名词。两者有重叠，应结合习惯搭配。
误区
不能机械规定 of 只用于具体物、from 只用于抽象物。free of charge 是固定用法。
写作迁移
可以用 free from bias / free of unnecessary complexity，具体语义不同。

Reliable research should be free from political pressure.

可靠的研究应免受政治压力影响。

P04 / S3 / 行为后果 / 消费 优先掌握

end up + -ing / adjective / prepositional phrase

最终做了某事或处于某状态，常含意外或不理想结果。

结构
end up doing；end up exhausted；end up in debt，均为合语法结构。
误区
不能用 end up to do 表达“最终做”；结果不一定是负面的。
写作迁移
较正式的因果论证可用 lead to / result in，但要重新安排主语。

People who compare themselves constantly may end up feeling inadequate.

不断与他人比较的人最终可能感到自己不够好。

P05 / S3 / 科技 / 教育 / 责任 优先掌握

use A as B

把 A 用作 B；L034 原句用此结构建立隐喻。

结构
use 为动词，A 为宾语，as B 说明用途或角色；as 不是像……一样。
误区
区分 use A as B（用作）与 compare A to B（比作）。
写作迁移
积极用途选 tool / guide；攻击用途才选 weapon。

We should use feedback as a guide for improvement.

我们应把反馈用作改进的指引。

P06 / S3 / 教育投入 / 社会行动 优先掌握

be worth + -ing / noun

值得做或值得付出；本歌涉及关系价值评估。

结构
The plan is worth considering：主语 plan 是被考虑的对象。
误区
worth 后不用 to do；值得尊敬与值得做事的句法不同。
写作迁移
It is worthwhile to invest in education 是另一种结构。

Protecting local traditions is worth sustained effort.

保护地方传统值得持续投入。

P07 / S2 / 文章概括 / 问题报告 优先掌握

mention something to someone / mention that…

向某人提及某事；可用于转述人物的自我描述。

结构
mention + 事情；to + 人；that 引出被提及的内容。
误区
mention about sth 通常多余；discuss 也不接 about 作直接宾语标记。
写作迁移
若强调证据呈现，可根据实际信息用 report / indicate，不能擅自加强确定性。

The survey mentions that many students lack a quiet place to study.

这项调查提到，许多学生缺少安静的学习场所。

P08 / S2 / 材料 / 工艺翻译 建议掌握

be made of / from

由……制成；材料表达可被用于文学比喻。

结构
made of 常关注可识别的构成材料；made from 常关注加工来源。
误区
这是常用区别，不是没有例外的硬规则；be made up of 表示由多个部分组成。
写作迁移
译具体材料时保持事实；人的贵金属比喻需按语境处理，不能当物理描述。

The frame is made of wood, while the paper is made from recycled fibers.

框架由木材制成，而纸张由再生纤维制成。

P09 / S2 / 叙事 / 文学阅读 建议掌握

stop someone cold

使某人突然停住、震惊或一时怔住。

结构
cold 在此作副词性强化成分，强调突然、彻底。
误区
不是把某人冻住；并不一定指恐惧，也可由意外感动引起。
写作迁移
正式分析可用 take someone by surprise / cause someone to pause。

The unexpected result stopped the team cold for a moment.

出人意料的结果让团队一时愣住。

P10 / SR / 关系 / 公共服务 优先掌握

take something for granted

把某物视为理所当然；这是从主题扩展出的表达，并非本歌原句。

结构
take + 宾语 + for granted；granted 形式固定。
误区
它也可表示未经检验就假定为真，须看上下文。
写作迁移
写作中指出被忽视的价值，再给出实际行动，比空泛劝告更有效。

We should not take clean water or public safety for granted.

我们不应把清洁用水或公共安全视为理所当然。

P11 / S1 / 习俗翻译 / 口头总结 建议掌握

wrap something up

包好某物；另可表示结束活动。

结构
具体物品用包装义；meeting / discussion 用结束义。
误区
代词通常放中间：wrap it up。不能只按 up 推断词义。
写作迁移
正式书面可用 conclude the meeting / discussion。

The chair wrapped up the meeting with a summary of the main decisions.

主持人总结了主要决定，结束了会议。

P12 / S3 / 成长 / 数字生活 建议掌握

be present / engage with the present

投入眼前的生活；这是根据主题形成的书面改写，不是固定歌词引文。

结构
be present 本义可指在场，语境中也可强调专注、投入。
误区
物理在场不必然等于情感投入；engage with 需说明对象。
写作迁移
更具体的表达是 give full attention to the people around us。

Learning to engage with the present can improve the quality of everyday relationships.

学会投入当下，可以改善日常关系的质量。

SYNTAX / 08 STRUCTURES

不只会翻译，还要看清关系

下面以原创句演示歌词涉及的结构类型，保留语境定位，但不补写或改造原歌词。

G01 / S1 / 句法迁移

让步：although / though

开篇让外在吸引力与主观限制感形成对照。

Although the opportunity looked attractive, it imposed severe limits on personal choice.

虽然这个机会看起来诱人，却严重限制了个人选择。

结构解析 让步从句 + 主句。英语通常不用 Although…, but… 双重连接；从句本身不否定主句事实。

迁移与限制 可迁移为 Although A…, B…；写作时把“承认的优点”与“真正的论点”分别放清楚。

G02 / SR / 句法迁移

with + 宾语 + 补足语

反复出现的交通场景包含伴随状态。

With several tasks unfinished, the students decided to postpone the trip.

几项任务尚未完成，学生们决定推迟旅行。

结构解析 with 是介词；tasks 是宾语；unfinished 是形容词化过去分词，说明任务状态。结构不是时态。

迁移与限制 补足语也可为 -ing、过去分词、形容词或介词短语；应根据主动、被动或状态关系选择。

G03 / S2 / S3 / 句法迁移

what 引导融合关系结构

愿望与关系判断中，可学习“所……的东西”结构。

Good education should provide what learners actually need.

良好的教育应提供学习者真正需要的东西。

结构解析 what learners actually need 整体作 provide 的宾语；what 兼有先行内容与从句内宾语功能，约等于 the things that。

迁移与限制 传统教学中常归入名词性从句。不是疑问句；不能叠加 the things what。

G04 / S2 / 句法迁移

限定性定语从句与关系代词省略

中段对物件与人物的描述可支持定语从句训练。

The support that young researchers need is often practical rather than symbolic.

青年研究者所需要的支持，往往是实际帮助而非象征性支持。

结构解析 that young researchers need 修饰 support；that 作 need 的宾语，可以省略。关系词作主语时通常不能这样省略。

迁移与限制 先还原 need the support 再判断：缺宾语用关系词作宾语；非限定性从句不可套用同样省略规则。

G05 / S1 / 句法迁移

should have + 过去分词

故乡回忆中出现回看过去的评价。

We should have checked the sources before sharing the claim.

在传播这项说法之前，我们本应核实来源。

结构解析 should have checked 通常表示对过去未做之事的批评或遗憾，但在预期语境中也可表示“到现在应该已完成”。

迁移与限制 歌曲中的具体价值判断属于人物视角，不能把它直接当作教师或歌手认可的标准。

G06 / S3 / 句法迁移

现在进行时与习惯性后果

L034 原句采用现在进行时；后段的后果表达可与之比较。

You are relying on old assumptions, and this may lead to misleading conclusions.

你正在依赖旧有假设，这可能导致误导性结论。

结构解析 are relying 描述当前阶段正在发生的行为；情态 may 表示可能后果。现在进行时不必局限于说话这一秒。

迁移与限制 写作中不要无依据地用现在进行时替代一般事实；陈述普遍现象常用一般现在时。

G07 / S1 / S2 / S3 / 句法迁移

省略、片段与口语拼写

转录中存在片段句与口语化写法。

The relationship was never formally acknowledged.

这段关系从未得到正式承认。

结构解析 这是用于说明语域的原创完整句，不是给歌词补定稿。片段句省去了成分时，主语或指代可能仍有歧义。

迁移与限制 正式作文用完整分句；口语中省去词尾或连接词的写法不能作为规范书面拼写范例。

G08 / SR / 句法迁移

延迟识别：not…until / It was not until…that…

结尾的迟来认识可迁移为标准强调句型。

It was not until the service disappeared that residents realized its value.

直到这项服务消失，居民们才意识到它的价值。

结构解析 it-cleft 强调 until 所引出的时间条件。that 后使用正常语序；不是 realized 才作主语。

迁移与限制 句首 Not until the service disappeared did residents realize its value. 才需要主句倒装；两种结构不能混搭。

05

WRITING / KEEP THE VALUE, CHANGE THE REGISTER

写作表达迁移

每项从已经学习的词或结构出发，改成规范书面表达。不要把文学比喻当作任何议论文都可直接套用的高级句。

W01 / 成长；历史与文化

nostalgia → acknowledge the past without idealizing it

原始表达：L034 nostalgia。

语言来源：nostalgia / S3。箭头右侧为书面语改写或主题拓展。

We can acknowledge the value of the past without idealizing it at the expense of present responsibilities.

我们可以承认过去的价值，而不应以牺牲当下责任为代价去美化它。

先承认价值，再说明边界。idealize 指理想化；at the expense of 强调牺牲另一项价值，是主题扩展表达。

W02 / 技术发展；劳动

liberate → liberate people from repetitive work

原始表达：L007 A liberated libertine。

语言来源：liberate / S1。箭头右侧为书面语改写或主题拓展。

Well-designed technology can liberate people from repetitive work and create space for more demanding tasks.

设计良好的技术可以让人摆脱重复劳动，为要求更高的任务腾出空间。

保留动词结构，但给出明确受益者和被解除的限制。不能只说 technology liberates 而省去关键对象。

W03 / 教育；公共宣传

capture attention → draw public attention to an issue

原始表达：L022 captured your attention。

语言来源：capture + attention / S2。箭头右侧为书面语改写或主题拓展。

A successful campaign should draw public attention to food waste and explain how individuals can reduce it.

成功的宣传活动应引起公众对食物浪费的关注，并解释个人如何减少浪费。

从私人吸引转成公共议题；draw attention to 比单纯“吸睛”更能承接论证对象。

W04 / 学习；专业发展

solid → establish a solid foundation for…

原始表达：L026 solid gold。

语言来源：solid / S2。箭头右侧为书面语改写或主题拓展。

Regular practice establishes a solid foundation for independent problem-solving.

经常练习为独立解决问题打下牢固基础。

把材料形容词迁移到抽象名词；foundation for 是基础指向某种能力或活动。

W05 / 消费；社会比较

end up doing → may lead to + noun / -ing

原始表达：L035 end up hurting。

语言来源：P04 / S3。箭头右侧为书面语改写或主题拓展。

Constant social comparison may lead to dissatisfaction even when material conditions improve.

即使物质条件改善，不断的社会比较仍可能导致不满。

歌词的口语结果结构改成因果表达；may 保留必要的不确定性。to 是介词。

W06 / 教育；志愿服务

worth → be worth sustained effort

原始表达：L043 worth it。

语言来源：worth / S3。箭头右侧为书面语改写或主题拓展。

Building mutual trust is worth sustained effort because cooperation depends on it.

建立相互信任值得持续投入，因为合作有赖于信任。

评估对象需具体；because 从句给出理由。不要用高级词掩盖缺乏论据。

W07 / 成长；反思与实践

use A as B → use reflection as a guide for action

原始表达：L034 using nostalgia as a weapon。

语言来源：P05 / S3。箭头右侧为书面语改写或主题拓展。

Students should use reflection as a guide for action rather than as a substitute for it.

学生应把反思作为行动的指引，而不是用反思代替行动。

把负面武器隐喻转成积极角色；rather than 后两个 as 短语平行。

W08 / 人际关系；责任

harm → undermine the quality of relationships

原始表达：L036 self-harm。

语言来源：harm / S3。箭头右侧为书面语改写或主题拓展。

Neglecting everyday responsibilities can undermine the quality of close relationships.

忽视日常责任可能损害亲密关系的质量。

undermine 是主题扩展词，指逐渐削弱；不宣称它出现在歌词中。具体指出损害对象。

W09 / 青年发展；社会价值

free of → free from unnecessary social pressure

原始表达：L022 free of all pretension。

语言来源：P03 / S2。箭头右侧为书面语改写或主题拓展。

Young people need room to explore their interests free from unnecessary social pressure.

年轻人需要免受不必要社会压力影响的空间，以探索自己的兴趣。

free from 修饰探索时的状态；避免把“摆脱压力”夸大为完全不负责任。

W10 / 公共服务；文化保护

delayed recognition → It is only when…that…

原始表达：L016 You never knew that it was Babylon。

语言来源：G08 / SR。箭头右侧为书面语改写或主题拓展。

It is often only when a local tradition begins to disappear that people recognize its social value.

人们往往要到一种地方传统开始消失时，才认识到它的社会价值。

强调句突出识别的时间条件；often 防止把观察写成无例外的断言。

ORIGINAL MODEL / 主题整合段落

Freedom requires attention to responsibility.

Personal freedom allows young adults to explore new possibilities, but it does not remove their responsibilities to others. Technology may liberate us from routine work and create more time for meaningful activities. Yet this advantage matters only if we use that time wisely. Instead of comparing every moment with an idealized past, we can use reflection as a guide for action. Giving attention to everyday commitments helps build a solid foundation for trust. A fulfilling life therefore depends not only on what we achieve, but also on how we treat the people who share it.

个人自由使年轻人能够探索新的可能，却不免除他们对他人的责任。技术可以让我们摆脱日常重复劳动，为有意义的活动腾出更多时间。但只有合理使用这些时间，这种优势才有意义。我们可以把反思作为行动的指引，而不是拿每一个当下与理想化的过去相比。关注日常承诺有助于为信任打下牢固基础。因此，充实的生活不仅取决于我们取得什么成就，也取决于我们如何对待与自己共同生活的人。

这是一段原创写作示范，不是歌词翻译，也不是符合某道真题题目的完整作文。结构：立场 → 科技例子 → 使用条件 → 行动建议 → 归结。可迁移词语来自本手稿；其余词语是自然衔接所需的原创扩展。

TRANSLATION / 03 LEVELS · 09 TASKS

汉译英专项训练

基础重搭配，进阶重关系，六级应用重信息组织。T07—T09 为段落式练习；它们是原创训练，不是官方真题。每题先写，再看答案。

T01 / 基础 / melody / nostalgia

这段熟悉的旋律唤起了我对童年的怀念。

查看 T01 参考答案与解析

This familiar melody evokes nostalgia for my childhood.

解析 唤起用 evoke；“对童年的怀念”用 nostalgia for。一般现在时适合说明稳定的情感效果；具体叙事也可用 evoked。

常见错误示例 This melody makes me recall about my childhood.

为什么要改 recall 通常直接接宾语，不用 about；若重点是怀旧情绪，nostalgia 更准确。

T02 / 基础 / attention

我们应更加关注身边人的需要。

查看 T02 参考答案与解析

We should pay more attention to the needs of the people around us.

解析 “关注”用 pay attention to；needs 常用复数表示多方面需要；around us 后置修饰 people。

常见错误示例 We should pay more attentions on others' needs.

为什么要改 此义 attention 不可数；常见搭配的介词是 to。

T03 / 基础 / worth / solid

可靠的结论值得认真核实。

查看 T03 参考答案与解析

Reliable conclusions are worth checking carefully.

解析 conclusions 是复数，谓语用 are；worth checking 使用主动形式，含“结论被核实”的意义。

常见错误示例 Reliable conclusions are worth to check carefully.

为什么要改 worth 后接 -ing，不接 to do；副词 carefully 修饰 checking。

T04 / 进阶 / liberate / G01

虽然科技能使我们摆脱重复劳动，它也可能带来新的责任。

查看 T04 参考答案与解析

Although technology can liberate us from repetitive work, it may also bring new responsibilities.

解析 让步关系用 although；liberate…from…；may 保留“可能”，不能擅自译成一定。

常见错误示例 Although technology frees us from work, but it brings responsibilities.

为什么要改 去掉 but；repetitive work 比全部 work 更符合原文；保留可能性。

T05 / 进阶 / mention / single 与 alone 的区分

她提到，独自生活不一定意味着缺少支持。

查看 T05 参考答案与解析

She mentioned that living alone does not necessarily mean lacking support.

解析 that 从句作 mention 的宾语；living alone 整体作从句主语；not necessarily 表示“不一定”。

常见错误示例 She mentioned about that living single means no support.

为什么要改 不用 mention about that；独居应译 living alone；不能遗漏“不一定”。

T06 / 进阶 / P04

有些人不断与他人比较，最终对自己的生活感到不满。

查看 T06 参考答案与解析

Some people constantly compare themselves with others and end up feeling dissatisfied with their own lives.

解析 compare themselves with others 交代比较双方；end up 后接 feeling；dissatisfied with 交代不满对象。

常见错误示例 Some people compare with others and end up to feel unsatisfied to their life.

为什么要改 compare 补足 themselves；end up feeling；用 dissatisfied with。这里 lives 对应多人的各自生活。

T07 / 六级应用 / nostalgia / stable / attention

保存旧照片能够唤起共同的记忆，但社区建设不能只依赖怀旧。它还需要稳定的公共服务和对现实问题的关注。

查看 T07 参考答案与解析

Preserving old photographs can evoke shared memories, but community development cannot rely on nostalgia alone. It also requires stable public services and attention to current problems.

解析 中文长句拆成两句；“只”用 alone；stable 在这里是形容词，区别于歌词中的名词用法。

常见错误示例 Community building cannot only depend on remembering old times, it needs safe services.

为什么要改 避免逗号拼接两个独立句；“稳定”不是 safe；怀旧不等于单纯记住往事。

T08 / 六级应用 / capture / attention / solid / 倒装拓展

优秀的教育不仅要吸引学生的注意，还要为独立思考打下牢固基础。只有当学生学会评估证据时，知识才能转化为判断力。

查看 T08 参考答案与解析

Good education should not only capture students' attention but also lay a solid foundation for independent thinking. Only when students learn to evaluate evidence can knowledge be transformed into sound judgment.

解析 not only…but also… 连接两个并列动词；Only when 位于句首，主句 can knowledge… 倒装。知识转化用被动语态。

常见错误示例 Only when students learn evidence, knowledge can become judgment.

为什么要改 “评估”不可遗漏；句首 Only when 要求主句倒装；sound judgment 更自然。

T09 / 六级应用 / capture 的记录义 / harm / G08

随着数字技术的发展，人们更容易记录生活中的重要时刻。然而，如果记录取代了真实的参与，我们可能直到一段关系受到损害，才意识到日常陪伴的价值。

查看 T09 参考答案与解析

解析 分开趋势与警示；find it + adj. + to do；not…until 对应“直到……才”；has been harmed 表示到意识发生时损害已形成。

为什么要改 people find it easier to… 才有完整谓语；companionship 是陪伴，company 容易误指公司；保留“可能”。
