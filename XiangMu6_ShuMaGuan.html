01.2

先看整体，再看语句

main反复调用display；display每次扫描8位；delay让当前位驻留。

01 / ENTRY启动代码初始化全局数据，进入main。
02 / LOOPwhile(1)条件恒真，调用display。
03 / SCANi=0；依次取位码并写P2。
04 / LOOKUP读取disbuffer[i]，用p查codevalue。
05 / OUTPUT段码写P0；驻留delay(20)。
06 / RETURN ↻i++，未满8位回③；满8位返回②。

扫描i属于display；延时i属于delay，两个局部变量互不混用。

这些流程描述C层语义。优化器可以改变指令安排，浏览器单步不等于8051逐指令调试。

01.4

delay(20)：20到底表示什么？

20是“循环上限”，不是毫秒单位，也不是20条指令。

把20传给delay中的形参i后，j从0开始，每轮比较j<i、执行空循环体、j++，直到j=20退出。虽然花括号中没有操作，判断、递增与跳转仍可能产生机器指令。

传统12T的AT89C51，机器周期Tmc=12/fosc。例如12MHz时为1μs，11.0592MHz时约1.085μs。但一个16位C循环不等于一个机器周期。

可用的计算框架：t≈(N固定+20×N循环)×12/fosc，其中N必须从实际反汇编核定；最终一次条件失败和调用返回的开销也要计入。若需要1ms且f=12MHz，总计应接近1000个机器周期；仅凭源码无法证明达到了这个数。

教材P188把delay(20)注释为1ms；当前工程没有提供晶振属性、Keil版本、优化等级和.LST/反汇编。这里保留原注释，讲解时标记为未校准估计。不能把20换成另一份延时函数的110后，宣称精确。

深入：怎样真正测准，以及空循环优化的影响
  1. 记录芯片型号、Clock Frequency、Keil版本、优化等级和存储模式。
  2. 在Keil查看生成的反汇编，确认循环是否保留，逐条按本芯片指令周期累加。
  3. 用调试器计时，或额外输出测试脉冲，用示波器测量，并扣除测试代码开销。
  4. 需要稳定刷新时，可独立设计硬件定时扫描方案；这属于修改建议，不是本原程序。

没有可观察副作用的空循环可能被优化改变甚至消除；不是断言当前Keil已删除它。应检查实际编译结果。

03.3

驻留时间与刷新频率

设每一位有效驻留时间为t，额外开销总计t额外。整轮T≈8t+t额外，每位刷新频率f=1000/T（T以ms计）。瞬时位切换频率约是每位刷新频率的8倍，两者不能混用。

计算器输入的是假设或实测值，没有将delay(20)自动认证为1ms。慢速播放是教学时间，与本计算器分离。

各位等时且忽略消隐、开销时，每位位选占空比约1/8。增加所有位的驻留时间，理想占空比仍接近1/8，同时刷新频率下降；亮度还取决于峰值电流、驱动和具体点亮段数。

深入：视觉暂留、闪烁与摄像条纹

快速交替的光脉冲会被视觉整合，但不存在适用于所有人和环境的“超过24Hz必定不闪”标准。低刷新、眼动、高亮度、低占空比、不同显示内容与相机滚动快门都可能暴露闪烁或条纹。稳定显示也不能证明电气电流符合规范。

04.1

让程序能运行的最小条件

部分本实验必须理解
AT89C518位CPU，片内Flash 4KB、RAM128B；本程序用软件循环刷新显示。
时钟经典12T：一个机器周期含12个振荡周期。实物使用晶体振荡/合规外部时钟；Proteus可能通过Clock Frequency属性模拟时钟。
复位RST为高有效，振荡运行条件下需满足手册复位时序；复位后端口锁存值为FFH。
电源U1 VCC40/GND20；U2 VCC20/GND10。隐藏引脚仍需正确连接电源网。
EA本例从片内程序存储器运行时应为高；不能把空着的EA当作实物推荐接法。
P0 / 80H8位可位寻址SFR；普通I/O开漏，高电平需要外部上拉。P0=段码不是让芯片输出“数字本身”。
P2 / A0H8位可位寻址SFR，具有内部上拉。当前按整字节给位选，低有效；实物需核对公共阴极总灌电流。
端口锁存值与引脚电压不是同一层概念

把0x5B写进P0寄存器表示各输出锁存位的目标状态；开漏写1是释放，引脚能否达到合格高电平要看外部电路。RP1若接地形成下拉，不会因为软件写1就变成上拉。模拟器中的P0读数标为“写入值”，不冒充电压测量。

位码移动的是一个0

原表常见数值逐一拆解

为什么不是放大器，也不是8位译码器

04.5

从静态显示到分时复用

比较项静态显示本项目动态显示
连接各位有独立的段数据通道/锁存保持。8位共享8条段线，另用8条直接位选。
程序数据写入后可由独立硬件保持。display持续逐位刷新；while(1)保证重复。
占空可持续点亮。等时轮询时每位理想约1/8。
代价用更多通道或扩展器件。软件占用CPU；时序不当有闪烁/重影。

本项目必须能复述的完整逻辑

将8个数字放入disbuffer。i从0到7，用chocode[i]选位，经P2输出；再用disbuffer[i]取得p，经codevalue[p]查出段码，写P0。正常控制条件下，经74LS373传到段线，当前位亮成目标数字。delay让该位驻留，然后换位；8位完成后不断重复。
